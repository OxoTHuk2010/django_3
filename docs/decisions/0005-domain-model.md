# 0005. Базовая доменная модель интернет-магазина

## Статус

Принято.

## Контекст

Проект реализует интернет-магазин на Django и DRF. Необходимо разделить бизнес-логику по приложениям и избежать монолитной модели внутри одного app.

## Решение

Используем следующие приложения:

- users — пользователи;
- catalog — категории, товары, изображения;
- cart — корзина;
- orders — заказы и позиции заказов;
- common — общие абстрактные модели.

## Причины

- упрощается сопровождение;
- каждая область ответственности изолирована;
- проще писать API, тесты и документацию;
- проект можно расширять без полной переработки структуры.

## Последствия

Появляется больше файлов и связей между приложениями, но структура становится чище и ближе к промышленной разработке.
