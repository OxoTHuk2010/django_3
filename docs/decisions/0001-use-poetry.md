# ADR 0001: Использование Poetry

## Статус
Принято

## Контекст

Проекту нужен единый способ управления зависимостями, виртуальным окружением и lock-файлом.

## Решение

Использовать Poetry.

## Причины

- фиксирует зависимости через `poetry.lock`
- упрощает установку окружения
- разделяет основные и dev-зависимости
- подходит для воспроизводимой разработки

## Последствия

+ Проект проще развернуть на другой машине
+ Зависимости контролируются явно
+ Удобно подключать dev-инструменты

- Нужно соблюдать дисциплину и не устанавливать зависимости через `pip install` напрямую
