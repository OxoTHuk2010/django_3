# ADR 0001: Использовать Poetry для управления зависимостями

## Статус

Принято.

## Контекст

Проект использует Python 3.12, Django, DRF, PostgreSQL, инструменты тестирования и линтинга. Нужно воспроизводимо устанавливать зависимости и фиксировать версии.

## Решение

Использовать Poetry как основной инструмент управления зависимостями и lock-файлом.

Основные файлы:

- `pyproject.toml`
- `poetry.lock`

## Последствия

Плюсы:

- воспроизводимые установки через `poetry.lock`;
- разделение main/dev зависимостей;
- единая точка конфигурации проекта.

Минусы:

- Dockerfile должен явно учитывать Poetry;
- разработчикам нужны базовые команды Poetry.

## Команды

```bash
poetry install
poetry add <package>
poetry add --group dev <package>
poetry run python manage.py check
```
