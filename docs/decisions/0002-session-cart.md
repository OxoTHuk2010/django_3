# ADR 0002: Гибридная корзина session + DB

## Статус

Принято.

## Контекст

Корзина нужна и гостю, и авторизованному пользователю. Гостевая корзина не должна требовать регистрации, но авторизованному пользователю нужна сохранность между устройствами и сессиями.

## Решение

- Гость хранит корзину в Django session.
- Авторизованный пользователь хранит корзину в БД через `Cart` и `CartItem`.
- После успешного входа session-cart объединяется с DB-cart.
- Корзина хранит только `product_id` и `quantity`.
- Цена, активность товара и остаток всегда читаются из актуального `Product`.
- Корзина не резервирует товар.
- Финальная проверка остатков выполняется в checkout внутри транзакции.

## Последствия

Плюсы:

- Гость может пользоваться корзиной без аккаунта.
- Авторизованный пользователь получает persistent cart.
- Checkout остаётся единственным местом финального списания остатков.

Минусы:

- Нужна логика merge при входе.
- Нужно нормализовать недоступные товары и битые `product_id`.
- Цена корзины не является snapshot и может измениться до checkout.

## Инварианты

- Нельзя добавить неактивный или soft-deleted товар.
- Нельзя добавить количество меньше `1`.
- Нельзя превысить остаток и системный лимит позиции.
- Merge не должен silently создавать недопустимое количество.
- Checkout пустой корзины запрещён.
