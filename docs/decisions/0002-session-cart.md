# ADR 0002: Session-based корзина

## Статус
Запланировано

## Контекст

Для web-интерфейса интернет-магазина нужна корзина до создания заказа.

## Решение

Использовать session-based корзину.

## Причины

- корзина не является заказом
- для MVP не требуется хранить корзину в БД
- неавторизованный пользователь сможет добавлять товары
- Django sessions достаточно для начальной реализации

## Последствия

+ Простая реализация
+ Меньше сущностей в БД
+ Подходит для MVP

- Корзина привязана к браузеру/сессии
- Нужна отдельная логика синхронизации, если позже появится persistent cart
