# ADR 0036: Русскоязычные demo-данные с ASCII technical keys

## Статус

Принято.

## Контекст

Часть исходного шаблона и demo-товаров содержит английские названия и тексты. Проект сдаётся как русскоязычный интернет-магазин `MyShop`.

Полная русификация всех значений, включая technical keys, может ухудшить стабильность URL, seed-данных и тестов.

## Решение

Runtime UI и seed demo data должны быть русскоязычными для пользователя.

Русифицируются:

- названия товаров;
- категории;
- описания;
- отзывы;
- имена покупателей;
- адреса;
- комментарии заказов;
- пользовательские UI-тексты.

Technical keys остаются ASCII:

- `slug`;
- `SKU`;
- `username`;
- `provider_payment_id`;
- имена fixtures, provider ids и стабильные seed keys.

## Последствия

Плюсы:

- публичная витрина выглядит цельно и соответствует русскоязычной сдаче;
- URL, тесты и seed-идемпотентность остаются стабильными;
- данные проще проверять в admin dashboard and analytics.

Минусы:

- видимые тексты и technical keys могут отличаться;
- seed tests должны проверять как русские display values, так и ASCII keys;
- при добавлении новых demo-data нужно соблюдать два набора правил.

## Инварианты

- Пользовательские названия и описания не остаются на английском без причины.
- Slug/SKU/username/provider ids остаются ASCII.
- `seed_demo_data` остаётся идемпотентной.
- Demo-данные не используют реальные персональные данные.

## Связанные конфликты

- `C038` — англоязычные demo/template данные vs русскоязычная сдача.
