# ADR 0003: Использование JWT для API

## Статус
Принято

## Контекст

Необходимо реализовать аутентификацию для REST API.

Варианты:

1. Session-based
2. Token-based (JWT)

## Решение

Использовать JWT (SimpleJWT)

## Причины

- Stateless
- Хорошо подходит для API
- Не требует хранения сессий
- Легко масштабируется

## Последствия

+ Удобно для фронтенда
+ Не требует sticky sessions

- Нужно реализовать refresh токены
- Нужно учитывать безопасность хранения токена на клиенте
